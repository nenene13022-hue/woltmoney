# Wolt Pro - מחשבון משמרות

אפליקציית PWA למעקב הכנסות, קילומטראז' והוצאות למשלוחני וולט. עובדת אופליין, אפשר להתקין על מסך הבית בטלפון, והנתונים נשמרים מקומית בדפדפן.

## מה חדש בגרסה הזו

- **טופס יומי מקוצר:** הכנסה, טיפים, המתנה, ק"מ ושעות בלבד - 5 שדות במקום 8. הגדרות הדלק (צריכה, מחיר, בלאי) עברו למסך הגדרות נפרד (סמל גלגל השיניים ⚙️ למעלה), כך שממלאים אותן פעם אחת ולא בכל יום מחדש.
- **מספר הנטו במרכז:** הסכום הכי חשוב - "נטו לתקופה הנבחרת" - מוצג עכשיו גדול ובראש המסך.
- שינוי בהגדרות משפיע רק על ימים חדשים; ימים שכבר נשמרו שומרים את התנאים שהיו בתוקף אז.

## מה יש בתיקייה

כל 8 הקבצים הבאים הם **קבצים בודדים בשורש** - אין שום תת-תיקייה, בכוונה, כדי למנוע בעיות בהעלאה:

- `index.html` - כל האפליקציה (עיצוב + לוגיקה)
- `manifest.json` - הגדרות ההתקנה כאפליקציה
- `sw.js` - Service Worker לתמיכה באופליין
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` - אייקוני האפליקציה

**חשוב מאוד:** יש להעלות את **כל 8 הקבצים ישירות לשורש הריפו**, בלי שום תיקייה מסביבם - לא `wolt-pro-app/` ולא `icons/`. אם GitHub יוצר תת-תיקייה כלשהי בזמן ההעלאה (למשל כי גררתם תיקייה שלמה), `index.html` לא יהיה בשורש - וזה הגורם השכיח ביותר לדף שמציג "404" במקום האפליקציה. לפני שממשיכים, חלצו (Extract/Unzip) את קובץ ה-ZIP במחשב - תראו שם 8 קבצים בודדים, בלי תיקיות בפנים.

## שלב 1: העלאה ל-GitHub (בלי שורת פקודה)

1. היכנסו ל-github.com והתחברו (או צרו חשבון חינמי).
2. לחצו על **+** למעלה מימין ← **New repository**.
3. תנו שם, למשל `wolt-pro` (אותיות אנגלית, בלי רווחים). השאירו **Public**. לחצו **Create repository**.
4. בעמוד הריפו החדש לחצו על **Add file ← Upload files**.
5. **פתחו את התיקייה המחולצת במחשב וסמנו את כל 8 הקבצים** (Ctrl+A / Cmd+A כדי לסמן הכל), וגררו את כולם יחד לתוך אזור ההעלאה. אין תיקיות לגרור - רק קבצים בודדים, כך שאין סיכון ל"השטחה" או "קינון" שגויים.
6. **בדקו לפני השמירה:** ברשימת הקבצים שמופיעה להעלאה, ודאו שיש בדיוק 8 שורות, כל אחת עם שם קובץ בלבד (בלי `/` בנתיב).
7. גללו למטה ולחצו **Commit changes**.

### חלופה למשתמשי Git

```bash
git init
git add index.html manifest.json sw.js icon-192.png icon-512.png icon-maskable-512.png apple-touch-icon.png
git commit -m "Wolt Pro app"
git branch -M main
git remote add origin https://github.com/<username>/wolt-pro.git
git push -u origin main
```

## שלב 2: הפעלת GitHub Pages

1. בריפו, היכנסו ל-**Settings** (בתפריט העליון).
2. בתפריט הצדדי לחצו **Pages**.
3. תחת **Build and deployment ← Source** בחרו **Deploy from a branch**.
4. תחת **Branch** בחרו `main` ותיקיית `/ (root)`, ואז **Save**.
5. חכו כדקה ורעננו את העמוד - יופיע קישור בסגנון:
   `https://<username>.github.io/wolt-pro/`

זה הקישור הקבוע לאפליקציה שלכם.

## שלב 3: התקנה על הטלפון

**אנדרואיד (כרום):**
פתחו את הקישור בכרום ← תפריט שלוש הנקודות ← **התקן אפליקציה** (או שיופיע באנר התקנה אוטומטי בתחתית המסך).

**אייפון (ספארי חובה, לא כרום):**
פתחו את הקישור ב-Safari ← לחצו על כפתור השיתוף (הריבוע עם החץ) ← **הוסף למסך הבית** ← **הוספה**.

לאחר ההתקנה תופיע איקונת האפליקציה על מסך הבית, ופתיחה שלה תיראה כמו אפליקציה רגילה (בלי שורת כתובת של דפדפן), כולל עבודה ללא אינטרנט לאחר הפעם הראשונה.

## עדכון האפליקציה בעתיד

1. ערכו את `index.html` (או כל קובץ אחר) ושמרו.
2. ב-GitHub: **Add file ← Upload files** והעלו שוב את הקובץ המעודכן (הוא ידרוס את הישן), או `git add` + `git commit` + `git push` אם עובדים עם Git.
3. GitHub Pages יתעדכן אוטומטית תוך כדקה.
4. בטלפון: סגרו את האפליקציה לגמרי ופתחו שוב פעמיים (בפעם הראשונה ה-Service Worker מזהה עדכון ומוריד אותו ברקע, בפעם השנייה הוא נכנס לתוקף). אם רוצים לוודא עדכון מיידי - אפשר גם למחוק את האפליקציה ולהתקין מחדש.

## פתרון תקלות

**האתר מציג "404" / עמוד ריק:**
כמעט תמיד הסיבה היא מבנה קבצים שגוי בריפו (ראו האזהרה למעלה). בדקו:
1. היכנסו לעמוד הראשי של הריפו ב-GitHub - האם רואים בדיוק 8 קבצים בשורש (בלי אף תיקייה)? אם יש תיקייה כלשהי (כמו `wolt-pro-app` או `icons`), זו הבעיה - מחקו את הקבצים שבפנים והעלו אותם מחדש ישירות לשורש, כקבצים בודדים.
2. בדקו **Settings ← Pages** - האם כתוב שם "Your site is live at..." עם קישור? אם כתוב "GitHub Pages is currently disabled" - בחרו מחדש Source=main, /(root) ולחצו Save.
3. ודאו שהריפו **Public** (ב-Settings הראשי) - Pages בחשבון חינמי לא עובד על ריפו פרטי.
4. ודאו שאתם נכנסים לכתובת המדויקת `https://<username>.github.io/<שם-הריפו>/` (עם קו נטוי בסוף), ולא לכתובת אחרת.

**עדכנתי את הקוד אבל בטלפון עדיין רואים גרסה ישנה:**
זה כמעט תמיד ה-Service Worker ששומר גרסה ישנה במטמון. מחקו את האפליקציה מהטלפון והתקינו מחדש מהקישור, או בדפדפן: הגדרות האתר ← נקה נתוני אתר/עוגיות עבור הקישור, ואז טענו מחדש.

**איבדתי את הקישור לאתר שלי:**
היכנסו לריפו ב-GitHub ← Settings ← Pages - הקישור המלא מופיע שם תחת "Your site is live at".

## חשוב לדעת על הנתונים

- כל הנתונים (ימי עבודה, סכומים, ק"מ) נשמרים **מקומית בדפדפן/באפליקציה בטלפון בלבד** - הם לא מועלים לשום שרת.
- זה אומר שהנתונים שייכים למכשיר הספציפי. אם מתקינים את האפליקציה בטלפון נוסף, הנתונים לא יסתנכרנו אוטומטית.
- מומלץ לגבות מדי פעם עם הכפתור **"גיבוי נתונים (JSON)"** באפליקציה, ולשמור את הקובץ במקום בטוח (למשל בדרייב). ניתן לשחזר גיבוי בכל עת עם הכפתור **"שחזור / ייבוא"**.
- אם מוחקים את היסטוריית הדפדפן/נתוני האתר בטלפון, הנתונים באפליקציה יימחקו - לכן גיבוי תקופתי חשוב.
